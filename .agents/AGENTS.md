# Project Rules & Behavioral Guidelines

## Critical Rules
1. **Always Create an Implementation Plan First:** Before making ANY code changes or executing modifications, ALWAYS write/update `implementation_plan.md` with `request_feedback = true` and wait for user approval!
2. **Never Garble English Translations:** Never perform destructive character-by-character string replacement on already-translated English prose.
3. **Clean Chapter Titles:** Automatically translate all Chinese chapter titles (e.g. `读书` -> `Reading / Indominus Dragon (1)`) so no Chinese characters remain in English title badges or dropdowns.
